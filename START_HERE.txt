🚀 MỖI LẦN CHẠY LẠI:

   │ cd backend                          │
   │ start_py312.bat                     │
   └─────────────────────────────────────┘
   → Backend chạy tại http://localhost:8000

   Cửa sổ Terminal 2 - Frontend:
   ┌─────────────────────────────────────┐
   │ cd frontend                         │
   │ npm run dev                         │
   └─────────────────────────────────────┘
   → Frontend chạy tại http://localhost:5173

📚 HƯỚNG DẪN CHI TIẾT:
   • QUICK_START.md       - Hướng dẫn nhanh
   • PYTHON312_SETUP.md   - Setup Python 3.12 chi tiết

🆘 GẶP LỖI:
