### 🌐 Link trực tiếp:

## 3. 🟨 **Draw.io (diagrams.net)**

### 🌐 Link trực tiếp:
- **Draw.io**: https://app.diagrams.net/
- **Diagrams.net**: https://www.diagrams.net/

### 📝 Cách sử dụng:
1. Mở link **Draw.io**
2. Chọn **Create New Diagram**
3. Template: **UML** → **Use Case Diagram**
4. Kéo thả các elements:
   - **Actor** (người dùng)
   - **Use Case** (hình oval)
   - **System Boundary** (hộp)
   - **Relationships** (mũi tên)
5. Export: **PNG**, **SVG**, **PDF**, **XML**

### ✨ Ưu điểm:
- ✅ WYSIWYG editor (vẽ tay)
- ✅ Nhiều template có sẵn
- ✅ Lưu vào Google Drive, OneDrive
- ✅ Collaborative (nhiều người cùng vẽ)

## 🖼️ **EXPORT SETTINGS CHO LUẬN VĂN**

### Recommended Settings:
```yaml
Format: PNG
Resolution: 300 DPI (minimum)
Size: A4 landscape (297×210 mm)
Background: White
Border: Yes (thin black line)
Font: Arial hoặc Helvetica
Font Size: 10-12pt
```

### PlantUML Export Commands:
```plantuml
' Thêm vào đầu file .puml
skinparam dpi 300
skinparam defaultFontSize 12
skinparam backgroundColor white
```

## 💡 **TIPS CHO LUẬN VĂN CHẤT LƯỢNG CAO**

### 1. **Sử dụng màu sắc nhẹ nhàng**
```plantuml
skinparam usecase {
    BackgroundColor LightBlue
    BorderColor DarkBlue
}
```

### 2. **Thêm chú thích (notes)**
```plantuml
note right of UC11
  Dual OCR Strategy:
  1. Tesseract (fast)
  2. EasyOCR (fallback)
end note
```

### 3. **Group related use cases**
```plantuml
rectangle "Invoice Management" {
    (Upload hóa đơn)
    (Xem danh sách)
}
```

### 4. **Làm rõ relationships**
```plantuml
UC5 .> UC11 : <<include>>
UC10 .> UC6 : <<extend>>
Admin --|> User
```

## ❓ **FAQ**

### Q: Tool nào tốt nhất cho luận văn?

### Q: Có cần cài phần mềm không?
